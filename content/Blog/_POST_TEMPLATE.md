# Example Retro Story

Start each post with a short paragraph summarizing the update. Keep total line width below ~70 characters so it renders cleanly in the BBS UI.

## Suggested Sections

- **Origin story:** Explain what inspired the update.
- **Hardware/software:** Mention tools, commands, or builds.
- **Screenshots or art:** Place images alongside this file (PNG/JPG) and reference them with `cat` commands in the main terminal experience. Images do not display inside the BBS view, so describe them with text.

## Closing Notes

Wrap up with a call to action or hint about the next update. The BBS reader strips most markdown styling, but headings and lists help keep content skimmable when converted to fixed-width text.
